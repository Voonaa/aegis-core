# Support Guidelines — Aegis Core Platform

Thank you for using Aegis Core! Here is how you can get help, ask questions, or report bugs.

## 🔍 Frequently Asked Questions (FAQ)

Before opening a support request, please read our [FAQ](https://voonaa.github.io/aegis-core/faq/) or check the [Troubleshooting Guide](https://voonaa.github.io/aegis-core/developer/) in the documentation. Most common issues regarding Windows WMI permissions, configuration, and diagnostics are covered there.

## 🐛 Reporting Bugs

If you find a bug:
1. Search the [GitHub Issues](https://github.com/Voonaa/aegis-core/issues) to see if it has already been reported.
2. If it is a new bug, create a new issue using our **Bug Report Template**.
3. Provide as much context as possible, including your Windows build version and log files (located in `%LOCALAPPDATA%\AegisCore\logs\`).

## 🛡️ Security Vulnerabilities

Please do not report security vulnerabilities via public issues. Refer to our [Security Policy](SECURITY.md) to report vulnerabilities privately via email.

## 💬 Community Support

For general questions, configuration help, and discussing ideas:
- Open a discussion in the [GitHub Discussions](https://github.com/Voonaa/aegis-core/discussions).
- Join our private Discord community (invite link available on your profile).
- Email the maintainers directly at `support@aegisplatform.local` (typical response time is within 48 hours).
