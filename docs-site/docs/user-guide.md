# User Guide Overview

This section covers the core usage scenarios for Aegis Core Platform, outlining how to monitor telemetry, apply performance optimizations safely, and generate diagnostic reports.

---

## Guide Index

Explore specific user guides:

### [⚡ Telemetry Monitoring](monitoring.md)
Learn how to interpret real-time hardware telemetry and navigate the dashboard's graphical widgets:
-   Understanding the **Health Score** calculation.
-   Monitoring active CPU temperature zones and memory allocations.
-   Reviewing S.M.A.R.T diagnostic attributes of local SSD/HDD storage drives.

### [🎯 System Optimization](optimization.md)
Discover how to tune your system for different workloads:
-   Choosing between **Performance**, **Balanced**, and **PowerSaver** presets.
-   Enabling safety boundaries to protect critical hardware hardware configurations.
-   Managing system rollback backups to reverse power profile configurations.

### [📊 Diagnostic Reporting](reporting.md)
Compile system health logs for audits or troubleshooting:
-   Generating rich Markdown and formatted JSON logs.
-   Exporting 7-day historical database trends to CSV or styled HTML tables.
-   Locating output files inside the `reports/` workspace.

---

## Headless Execution
If you prefer managing Windows systems without launching a graphical user interface, you can run all diagnostic commands directly via the command-line interface. Check out the [💻 CLI Reference](cli.md) for full commands and syntax options.
