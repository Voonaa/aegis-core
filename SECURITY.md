# Security Policy

## Supported Versions

Only the latest production release version of Aegis is actively supported with security updates.

| Version | Supported |
| :--- | :---: |
| v1.0.0 | True |
| < v1.0.0 | False |

## Reporting a Vulnerability

We take the security of the Aegis Core Platform seriously. If you find any vulnerabilities or security flaws, please do not open a public GitHub issue. Instead, report it privately to help protect users.

Please report vulnerabilities by emailing the maintainers directly at support@aegisplatform.local or contact via private Discord channel.

We attempt to review and respond to all reports within 48 hours, detailing target fix schedules.
